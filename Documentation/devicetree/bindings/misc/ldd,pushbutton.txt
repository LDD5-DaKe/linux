* HSD/LDD5 FH-Hagenberg pushbutton device controller

This file describes the bindings for the pushbutton device for
LDD5 assignment 4.
The instantiated driver will be able to control the brightness of
a single led.

Required properties for the driver:
- reg: address of the register of the pushbutton control
- compatible: must be "ldd,pushbutton"!
- interrupts: configuration for the desired behaviour
- interrupt-parent: interrupt controller

Example:
pushbuttons: pushbutton@0xff200050 {
	compatible = "ldd,pushbutton";
	reg = <0xff200050 0x4>;
	interrupts = <0x0 0x29 0x4>; // level triggered shared peripheral interrupt
	interrupt-parent = <&intc>;
};
